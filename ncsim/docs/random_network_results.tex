\section{Evaluation Setup}

Does the relative performance ranking of HEFT, HEFT-1, and HEFT-2 hold
on random graphs?  We place \textbf{50 nodes} uniformly at random in an
$L\times L$ square and create bidirectional links between all pairs within
$R=80$\,m.  Varying $L$ controls network density.  We run the same
DAGs, routing schemes, and interference model as the grid evaluation.

\section{Analysis}

\subsection{HEFT-1 Dominance Is Robust Across All Densities}

On the regular 7$\times$7 grid, HEFT-1 dominated HEFT and HEFT-2 by
$3$--$7\times$ because csma\_bianchi interference made multi-hop
transfers prohibitively expensive, and the uniform grid gave the
greedy co-location heuristic many same-node placement options.
The random-graph experiments confirm this dominance is not an artifact
of the grid structure:

\begin{itemize}
  \item \textbf{Large DAG:} HEFT-1 wins at every density level.
    At the densest setting (L150, avg.\ degree 24.0) the best HEFT-1
    makespan is 149.9\,s vs.\ 287.3\,s for calibrated HEFT and 308.5\,s
    for HEFT-2---a $1.9$--$2.1\times$ advantage.  At the sparsest setting
    (L500, avg.\ degree 3.7) HEFT-1 still wins: 694.2\,s vs.\ 3914.5\,s
    for HEFT and 5068.6\,s for HEFT-2---a $5.6$--$7.3\times$ advantage.
  \item \textbf{Small DAG:} HEFT-1 wins at every density level, with
    makespans in the range 20--27\,s regardless of density, while HEFT
    ranges from 29\,s to 247\,s and HEFT-2 from 28\,s to 174\,s.
  \item The HEFT-1 advantage is \emph{larger} at low density.  When
    nodes are sparse, multi-hop paths grow longer and relay interference
    is more severe; HEFT-1's co-location bias avoids this cost, whereas
    calibrated HEFT spreads tasks across nodes forced into long paths.
\end{itemize}

\subsection{SH vs.\ S: A Density-Dependent Reversal}

On the 40\,m grid evaluation, shortest-path-by-delay (S) outperformed
shortest-hop (SH) because diagonal links (56.6\,m, lower BW) competed
with 2-hop cardinal paths (40\,m, higher BW)---S correctly preferred
the higher-bandwidth 2-hop route.

On random graphs the result reverses for the large DAG at high to medium
density:

\begin{itemize}
  \item At L150 (deg 24.0): SH wins for both HEFT and HEFT-2
    (HEFT/SH = 287.3\,s vs.\ HEFT/S = 292.1\,s;
     HEFT-2/SH = 308.5\,s vs.\ HEFT-2/S = 328.1\,s).
  \item At L200 (deg 17.1): SH wins for all three schedulers.
    The margin is largest for HEFT-1: HEFT-1/SH = 391.4\,s vs.\
    HEFT-1/S = 432.2\,s (11\% improvement).
  \item At L300--L350 (deg 6.7--8.7): SH still wins under HEFT-1
    (HEFT-1/SH = 362--405\,s vs.\ HEFT-1/S = 429--449\,s).
  \item At L250 (deg 12.4) and L400--L500 (deg $\leq$ 5.8):
    S regains the lead for HEFT-1.
\end{itemize}

\noindent The reversal is explained by the nature of random graphs at
high density: nodes are placed uniformly at random in a bounded area, so
the majority of within-range links have very similar lengths and therefore
similar PHY rates.  When bandwidth variation across links is small, the
key cost of a longer path is the number of relay transmitters it adds to
the interference graph.  SH's primary objective of minimising hop count
directly minimises that interference cost; S's delay-minimising objective
provides no advantage when all links have similar bandwidth.

\subsection{Best Routing Transitions with Density}

The optimal routing scheme under HEFT-1 shifts as density decreases:

\begin{itemize}
  \item \textbf{Dense (avg.\ degree $\geq 17$):} SH (large DAG) or S
    (small DAG).  Many short 1-hop paths exist; SH exploits them and
    avoids relay interference.
  \item \textbf{Medium-dense (avg.\ degree 8--13):} SH dominates for
    large DAG; S competitive for small DAG where shorter task chains
    reduce sensitivity to routing choice.
  \item \textbf{Sparse (avg.\ degree $\approx 6$):} W (widest-path)
    wins for large DAG at L400 (HEFT-1/W = 927.5\,s).  When the
    network has few alternative paths, maximising the bottleneck
    bandwidth on the chosen path outweighs hop-count minimisation.
  \item \textbf{Very sparse (avg.\ degree $\approx 4$):} GSD-D wins
    for large DAG at L500 (HEFT-1/GSD-D = 694.2\,s vs.\
    HEFT-1/W = 906.9\,s, HEFT-1/S = 792.8\,s).  This is the first
    experiment in either grid or random evaluations in which GSD-D
    wins under HEFT-1 for a large DAG.  At this density, path options
    are limited but GSD-D's deferral mechanism avoids the worst
    interference collisions that occur when all tasks must communicate
    over the same sparse set of bottleneck links.
\end{itemize}

\subsection{Random vs.\ Grid Topology}

Two structural differences explain the divergence from grid results:

\begin{enumerate}
  \item \textbf{Non-uniform node degree.}  In a random geometric graph,
    degree follows a roughly Poisson distribution.  Hub nodes (high
    degree) attract HEFT-1 placements because they can serve multiple
    tasks locally; leaf nodes (degree 1--2) are effectively unreachable
    for co-location.  On the grid every interior node has degree 8
    (with diagonals), so placement options are uniform.
  \item \textbf{Path length and BW homogeneity.}  On the 40\,m grid,
    diagonal links (56.6\,m) have meaningfully lower BW than cardinal
    links (40\,m), creating the strong S$>$SH ordering.  On random
    graphs at high density, inter-node distances within the 80\,m
    comm range are drawn from a near-uniform distribution, so link BWs
    cluster tightly---making hop count rather than per-link BW the
    dominant routing cost.
\end{enumerate}
