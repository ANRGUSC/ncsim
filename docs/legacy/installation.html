1. Prerequisites

ToolMinimum VersionCheck Command
Python3.10+python --version
pip21+pip --version
Node.js18+node --version
npm9+npm --version
Git2.30+git --version
Node.js is only required for the visualization frontend. If you only need the headless CLI simulator, Python alone is sufficient.

2. Clone the Repository

git clone https://github.com/anrg-lab/ncsim-standalone.git
cd ncsim-standalone

3. Install ncsim (Simulator)

ncsim installs as a Python package using pip. From the repository root:

# Standard install
pip install -e .

# With development/testing dependencies
pip install -e ".[dev]"

This installs three dependencies: anrg-saga (scheduling algorithms), networkx (graph operations), and pyyaml (scenario parsing).

After installation, the ncsim command should be available:

ncsim --version
# ncsim 0.2.0

4. Install the Viz Backend

The visualization backend is a lightweight FastAPI server that runs ncsim experiments and serves results to the frontend.

pip install -r viz/server/requirements.txt

This installs fastapi and uvicorn.

5. Install the Viz Frontend

The frontend is a React + TypeScript application built with Vite.

cd viz
npm install
cd ..

6. Running ncsim (CLI)

The headless CLI runs a simulation from a YAML scenario file and writes results to an output directory.

ncsim --scenario scenarios/demo_simple.yaml --output output/demo

Expected output:

=== Simulation Complete ===
Scenario: Simple Demo
Scheduler: heft
Routing: direct
Interference: proximity
  radius=15.0
Seed: 42
Makespan: 3.001000 seconds
Total events: 7
Status: completed

Output files are written to the specified directory:

FileContents
scenario.yamlCopy of the input scenario (with defaults filled in)
trace.jsonlEvent trace — one JSON object per line for every simulation event
metrics.jsonSummary metrics (makespan, utilization, task assignments, etc.)

CLI Options

FlagTypeDefaultDescription
--scenariopathrequiredPath to scenario YAML file
--outputpathrequiredOutput directory for results
--schedulerchoicefrom scenarioheft, cpop, or round_robin
--routingchoicefrom scenariodirect, widest_path, or shortest_path
--interferencechoicefrom scenarionone, proximity, csma_clique, or csma_bianchi
--seedintfrom scenarioRandom seed for reproducibility
--interference-radiusfloat15.0Radius for proximity interference (meters)
--tx-powerfloat20WiFi transmit power (dBm)
--freqfloat5.0WiFi carrier frequency (GHz)
--path-loss-exponentfloat3.0Path loss exponent for WiFi models
--wifi-standardchoiceaxn, ac, or ax
--rts-ctsflagoffEnable RTS/CTS handshake
--verbose, -vflagoffEnable verbose logging
--versionflag—Print version and exit

7. Running the Viz Platform

The visualization platform requires two processes: a Python backend and a Node.js frontend.

Terminal 1: Start the Backend

cd viz/server
python run.py
# FastAPI server on http://localhost:8000

Terminal 2: Start the Frontend

cd viz
npm run dev
# Vite dev server on http://localhost:5173

Open http://localhost:5173 in your browser.

Proxy: Vite's dev server proxies /api/* requests to the FastAPI backend on port 8000. Both servers must be running for experiments to execute. The "Visualize Existing" mode can load pre-generated sample runs without the backend.

8. Verifying Your Installation

8.1 Verify the CLI

# Run the demo scenario
ncsim --scenario scenarios/demo_simple.yaml --output output/verify

# Check output files exist
ls output/verify/
# scenario.yaml  trace.jsonl  metrics.json

8.2 Verify the Viz Platform

  1. Start both servers as described in Section 7.
  2. Open http://localhost:5173 — you should see the home page with "Configure & Run" and "Visualize Existing" cards.
  3. Click "Visualize Existing" — you should see at least one saved experiment (demo-simple).
  4. Click on it — the Overview tab should show metrics including makespan.

8.3 Run the Test Suite

# Install dev dependencies if you haven't
pip install -e ".[dev]"

# Run tests
pytest

9. Troubleshooting

ProblemCauseFix
ModuleNotFoundError: No module named 'ncsim' ncsim not installed or wrong Python environment Run pip install -e . from the repository root. Check which python points to the right env.
ncsim: command not found pip scripts directory not on PATH Use python -m ncsim.main instead, or add pip's bin directory to your PATH.
Frontend shows "Network Error" on Run Backend not running or CORS issue Ensure python run.py is running on port 8000. Check the terminal for errors.
Port 8000 or 5173 already in use Another process occupying the port Find and stop the conflicting process, or change the port in the respective config file.
npm install fails Node.js version too old Upgrade to Node.js 18 or later. Check with node --version.
Viz loads but "Visualize Existing" shows no experiments Sample runs directory missing or empty Check that viz/public/sample-runs/ contains at least one subdirectory with results files.
ImportError: anrg-saga Dependency not installed Run pip install -e . again — this will install all dependencies including anrg-saga.
